# 요구사항과 수용 기준

## 범위

MVP는 macOS 로컬 앱으로, 전역 단축키 → 두 가지 영역 선택 → 화면 캡처 → 즉시 이미지 클립보드 저장을 제공합니다. 이름 `sshot`은 저장소 및 임시 제품 이름입니다.

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| R01 | 전역 단축키로 진입 | 다른 앱이 활성화되어도 캡처 UI를 열고, 충돌·등록 실패를 알리며 단축키를 바꿀 수 있음 |
| R02 | 고정 사각형 마스크 | 영역을 이동·크기 조절하고 명시적 캡처 버튼 또는 Enter로 확정함. 같은 실행 세션에서 마지막 영역을 재사용하며 잘못된 화면 영역은 보정함 |
| R03 | 즉시 드래그 선택 | 포인터 누름 → 드래그 → 놓음으로 유효한 영역을 선택하고 바로 캡처함. 역방향 드래그도 동일하게 동작함 |
| R04 | 즉시 클립보드 저장 | 성공한 캡처 이미지를 NSPasteboard에 PNG 및 호환 가능한 이미지 표현으로 기록하고 복사 완료를 알림. 별도 썸네일 클릭·복사 메뉴가 필요 없음 |
| R05 | 일반 붙여 넣기 | 사용자가 대상 앱에서 ⌘V를 누르면 지원되는 이미지 입력란에 붙여 넣어짐. 앱이 자동으로 키 입력을 전송하지 않음 |
| R06 | 권한 상태 처리 | 화면 기록 권한 미허용·거부·철회 시 설명과 설정 이동 안내를 제공하고 캡처·클립보드 변경을 중단함 |
| R07 | 화면 및 픽셀 정확성 | 다중 디스플레이, 음수 원점, 서로 다른 Retina 배율에서 선택 영역과 결과가 일치함. 한 디스플레이 내부 캡처를 초기안으로 제안하며 경계 횡단 정책은 D04에서 확정함 |
| R08 | UI가 없는 결과 | 마스크·핸들·버튼·커서 강조 등 앱의 캡처 UI가 결과에 포함되지 않음 |
| R09 | 안전한 취소·실패 | Escape, 무효/0 크기 선택, 캡처 실패 시 기존 클립보드를 그대로 유지하고 UI를 정상 복구함 |
| R10 | 중복 실행 방지 | 캡처 중 단축키 반복 입력에도 중복 요청·오버레이·클립보드 쓰기가 생기지 않음 |
| R11 | 로컬 개인정보 보호 | 이미지 자동 파일 저장·원격 전송이 없고 진단 로그에 화면/클립보드 내용이 없으며 임시 이미지는 작업 종료 후 해제됨 |
| R12 | 운영 및 접근성 | 메뉴 막대에서 두 모드·설정·종료에 접근하고 키보드로 모드 선택·확정·취소 가능. 오류 후 재시도와 화면 변경 후 재사용 가능 |

기본 단축키 후보는 `⌃⇧⌘5`입니다. macOS의 `⇧⌘5`와 겹치지 않게 제안한 값이며 다른 앱과의 충돌은 기술 검증 및 사용자 환경에서 확인합니다. 기본값·변경 UI는 D03에서 확정합니다.

R01의 기본안은 메뉴 막대 상주 프로세스입니다. 이 방식은 첫 직접 실행이 필요하며 앱 종료 후 단축키가 작동하지 않습니다. 종료 상태의 단축키 실행(cold launch)이 필요한지 단계 1의 D09에서 확인하고, 필요하면 launcher 또는 로그인 시작 방식과 운영 범위를 결정합니다.

고정 영역 재사용은 메모리에서만 시작합니다. 앱 재실행 이후 위치·모드 저장은 후속 결정이며 화면 이미지 저장과는 구분합니다. 마지막 영역이 없는 경우 현재 디스플레이 중앙에 기본 사각형을 제시합니다.

## 제외 범위

전체 화면·창 단위 캡처, 스크롤 캡처, 동영상, OCR, 편집·주석, 파일 자동 저장, 클라우드 동기화, 캡처 기록, 자동 붙여 넣기는 MVP 범위 밖입니다. 다중 화면 합성 여부는 D04, 로그인 시작·cold launch 여부는 D09에서 확정합니다.

## 실패 후 사용자 경험

실패 원인을 짧게 표시하고 기존 클립보드는 보존합니다. 권한 안내가 필요한 경우 시스템 설정 경로를 제시합니다. 캡처를 완료하거나 취소하면 오버레이를 제거하고 이전 앱으로 돌아갈 수 있어야 합니다. 권한 설정과 배포 환경에 따른 재실행 필요 여부는 실제 OS별 검증 결과로 안내합니다.
